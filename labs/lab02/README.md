# Лабораторна робота №2: Розробка консольних утиліт для задач кібербезпеки

**Варіант 9:** Аудитор безпеки HTTP-заголовків відповідей.

## Установлення залежностей
Для роботи скриптів необхідно активувати віртуальне середовище та встановити залежності проєкту командою з кореня репозиторію:

pip install -r requirements.txt

## Структура вхідних даних
Програма приймає на вхід JSON-файл із дампами HTTP-заголовків. Згідно з архівом `lab2_data.zip`, файли повинні бути розміщені у такій структурі:

labs/lab02/data/data_v09/
├── headers.json       # Вхідний файл із дампами заголовків


## Приклади запуску
Усі команди необхідно виконувати з кореня репозиторію.

**Запуск демонстрації Завдання 1 (ООП):**
python -m labs.lab02.main demo

**Запуск Завдання 2 (Аудитор HTTP-заголовків):**
python -m labs.lab02.main analyze --headers-file labs/lab02/data/data_v09/headers.json --output-csv labs/lab02/data/data_v09/headers_audit.csv --strict --log-level INFO

## Опис параметрів CLI для команди analyze
* **`--headers-file`**: Шлях до вхідного JSON-файлу заголовків (за замовчуванням: `labs/lab02/data/data_v09/headers.json`).
* **`--output-csv`**: Шлях для збереження підсумкового звіту у форматі CSV (за замовчуванням: `labs/lab02/data/data_v09/headers_audit.csv`).
* **`--strict`**: Прапорець для увімкнення режиму суворої оцінки безпеки (віднімає 25 балів за відсутній заголовок замість 20).
* **`--log-level`**: Рівень деталізації журналу подій.

## Поведінка при помилках
* **Відсутність вхідного файлу**: Якщо файл, вказаний у `--headers-file`, не знайдено, програма записує подію в лог та генерує виняток `FileNotFoundError`.
* **Некоректний формат email (Завдання 1)**: При спробі встановити email, що не відповідає регулярному виразу, викидається виняток `ValueError`.
* **Некоректний формат JSON (Завдання 2)**: Якщо структура JSON не є словником або списком, скрипт згенерує помилку `ValueError("Невідомий формат JSON")`.
* **Доступ до неіснуючих ключів (Завдання 1)**: При зверненні до невідомого ключа в об'єкті `UserAccount` викидається `KeyError`.
* **Неправильний тип (Завдання 1)**: Присвоєння неправильного типу значення за ключем викликає `TypeError`.
